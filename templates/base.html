{% if lang == 'EN' %}The Blood Bank Management System is developed as an educational project for Data Structures & Algorithms. It simulates real-world hospital blood bank operations, managing blood bag inventories, requests, and distributions efficiently.{% else %}ระบบจัดการคลังเลือด (Blood Bank Management System) พัฒนาขึ้นเพื่อเป็นโปรเจกต์ศึกษาด้านโครงสร้างข้อมูลและอัลกอริทึม (Data Structures & Algorithms) โดยจำลองกระบวนการทำงานจริงของธนาคารเลือดโรงพยาบาล ช่วยบริหารจัดการสต็อกถุงเลือด คำขอรับเลือด และการจ่ายเลือดตามหลักการแพทย์{% endif %}

⚙️ {% if lang == 'EN' %}How to Use the System{% else %}วิธีการใช้งานระบบ{% endif %}

  • Dashboard: {% if lang == 'EN' %}View overall blood inventory statistics and urgent requests.{% else %}ดูภาพรวมสถิติคลังเลือดและคำขอเร่งด่วน{% endif %}
  • Blood Inventory: {% if lang == 'EN' %}Manage blood bags in inventory using a Linked List structure.{% else %}จัดการถุงเลือดในคลังผ่านโครงสร้าง Linked List{% endif %}
  • Hospitals: {% if lang == 'EN' %}Manage hospital data and storage rooms.{% else %}จัดการข้อมูลโรงพยาบาลและห้องเก็บเลือด/ตู้แช่{% endif %}
  • Blood Requests: {% if lang == 'EN' %}Manage request queues using Queue and prioritize using Priority Queue.{% else %}จัดการคิวคำขอด้วย Queue และจัดลำดับความสำคัญด้วย Priority Queue{% endif %}
  • Distribution (FEFO): {% if lang == 'EN' %}Distribute blood using the FEFO principle and record history with a Stack.{% else %}จ่ายเลือดตามหลัก First Expired, First Out และบันทึกประวัติด้วย Stack{% endif %}

Data Structures Implemented

1. Linked List: {% if lang == 'EN' %}Store and manage blood bag items via linked nodes.{% else %}จัดเก็บและจัดการรายการถุงเลือดแบบเชื่อมโยง Node{% endif %}
2. Queue: {% if lang == 'EN' %}Manage hospital blood request queues using FIFO.{% else %}จัดการคิวโรงพยาบาลที่ขอเลือดแบบ FIFO{% endif %}
3. Priority Queue: {% if lang == 'EN' %}Prioritize requests (Critical ➔ Urgent ➔ Normal).{% else %}จัดลำดับความเร่งด่วน (Critical ➔ Urgent ➔ Normal){% endif %}
4. Stack: {% if lang == 'EN' %}Store recent distribution history using LIFO.{% else %}จัดเก็บประวัติการจ่ายเลือดล่าสุดแบบ LIFO{% endif %}
